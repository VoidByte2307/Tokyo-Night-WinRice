# 🌃 Tokyo-Night-WinRice

My heavily customized Windows 11 desktop built around the **Tokyo Night** color scheme, **Komorebi**, and **YASB**.

This setup goes beyond configuration files: my daily YASB build also contains custom source-code modifications for behavior that isn't available in the stock version.

![Tokyo Night Windows Rice](screenshots/desktop-main.png)

## ✨ What's Included

- 🌃 Tokyo Night visual theme
- 🪟 Komorebi tiling window manager configuration
- 📊 Custom YASB configuration and styling
- ✨ Window animations and transparency
- 🖥️ Multi-monitor workspace layouts
- 🔧 Application-specific Komorebi rules
- 🧩 Custom YASB source modifications
